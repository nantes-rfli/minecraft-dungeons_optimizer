# Formal Serialized Relation / Reference v1

This boundary covers three fixed source fields: Scatter Crossbow `AttackDefintion.ProjectileDefinition[*].Projectile`, Battle Robe `GearActor`, and Death Cap Mushroom `Effect`. The committed artifact is [serialized-relation-v1.json](../research/domain/formal/serialized-relation-v1.json). Generate with `npm run generate:formal-serialized-relation`; verify with `npm run audit:formal-serialized-relation`.

A semantic relation contains the source Domain ID from a matched Formal Identity resolution, the category-specific relation reference, an occurrence, and the observed serialized target object name and `/Game/...` package path. The same-source Formal Identity result and its Raw evidence must be supplied as Relation input; missing or unresolved Identity yields no occurrence. It does not assert a target Domain entity, target gameplay semantics, or target availability. The provisional Battle Robe identity is valid while matched.

The projection reference is derived solely from the relation reference and occurrence. Scatter occurrences use validated unique `sourceIndex` values from the projected ProjectileDefinition collection. Missing or duplicate indices make the parent collection unavailable and yield no child records; an empty decoded collection yields zero children. Battle Robe and Death Cap each have one fixed occurrence when source Identity matches. A failed relation field still produces an unavailable record. Projected records have exactly one semantic relation and a target resolution; unavailable records have neither.

A relation is projected when the source ObjectProperty, unique class import, and unique root Package import agree internally, including their Raw name and index representations. The class name is observed, not fixed to `BlueprintGeneratedClass`. An internally consistent target drift remains projected. Target resolution separately records whether a target Raw snapshot was supplied. Each of the three slices defines its own fixed serialized target path and Raw package path correspondence; supplied snapshots are also checked for schema, dataset ID, and both source fingerprint fields. `resolved` means only that the target package snapshot corresponds to the serialized path. Battle Robe currently has no supplied target; Scatter Crossbow and Death Cap Mushroom resolve their supplied target packages.

Relation evidence points to actual source nodes or collections and imports. Target resolution cites separate package-level evidence without a node pointer. Evidence identity is based on Raw provenance, independent of occurrence or failure state, and can be shared. The audit rebuilds required occurrences from supplied Raw and same-source Formal Identity, compares all semantic, projection, and evidence content, and verifies every evidence pointer and observed content against the committed Raw snapshots. Application and Data Browser behavior is unchanged.
