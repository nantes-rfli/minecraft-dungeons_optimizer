## Implementation priority (model judgment)

Implementation priority judgment, not game strength or measured probability. Each dimension 1–5; high complexity/feedback/targeting scores are costs. Scores order research work, never override blockers.

Formula: `2*gameplayUsefulness + buildDiversity + 2*subsystemReuse + 2*evidenceQuality + 2*powerAvailability - implementationComplexity - feedbackComplexity - targetingUncertainty`. Benefit scores and costs each use 1–5. Cost subtraction intentionally penalizes unknown targeting and new feedback loops. Runtime retained rows have no score.

## Phase 2-2B — conditional batch

### Shock Powder

公開4点を境界付き区分線形で実装。対象割合・免疫・duplicate・有限初回使用は明示的なLimited境界。

- Reuse: Control / refreshCoverage
- New state: Power別duration、使用ごとの対象coverage
- Expected boundary: Limited: Power12–262、target割合、1copy境界。
- Gate: runtime

### Gong of Weakening

2x増幅は確認。durationと同名Weakening overlapが解決するまで登録しない。

- Reuse: EnemyDebuff / Damage modifiers
- New state: vulnerability、Gong Weakening所有者、対象・重複coverage
- Expected boundary: Limited: 検証済みduration/target/overlap境界。
- Gate: evidence-required

### Fishing Rod

1.5s CDは整合。3s履歴とPower scalingの関係を先に解決。

- Reuse: Control / activation
- New state: 対象選択、空振り・拾得物、pullとstunの免疫
- Expected boundary: Limited: 敵target成功率とPower範囲を明示。
- Gate: evidence-required

## Phase 2-2C — conditional batch

### Soul Healer

有限Soul schedulerは完成。旧低Power表を1.17の現行heal分布へ接続できず、乱数意味も未解決のためResearch-onlyを維持。

- Reuse: Soul trajectory / Healing
- New state: 固定50消費、HP不足・自己target share
- Expected boundary: Limited: soloまたは明示party share、測定Power域。
- Gate: evidence-required

### Harvester

有限Soul schedulerは完成。4/8秒のCD矛盾、現行高Power曲線、AoE targetと非Soul撃破feedbackが未解決のためResearch-onlyを維持。

- Reuse: Soul / DamageEvent / kill attribution
- New state: 40消費、AoE対象、Soulを落とさない撃破source
- Expected boundary: Limited: CD確定、測定damage範囲、AoE仮定。
- Gate: evidence-required

### Lightning Rod

有限Soul schedulerは完成。2/4秒のCD照合、現行高Power曲線、strike delay/target成功率、撃破Soul適格性が未解決のためResearch-onlyを維持。

- Reuse: Soul / DamageEvent
- New state: 遅延strike、対象維持、15消費
- Expected boundary: Limited: CD・Power・strike coverage。
- Gate: evidence-required

## Phase 2-2D — conditional batch

### Powershaker

係数259だけではcurve不明。multi-target consumeとVoid/Criticalの根拠を先に確保。

- Reuse: ChargeConsume / DamageEvent
- New state: 15秒または5爆発、per-target消費、間接damage
- Expected boundary: Limited: 対象・hit/miss・modifier境界。
- Gate: evidence-required

### Wind Horn

低Powerの5帯域のみ。endgame距離とslow値なしでは登録しない。

- Reuse: Control target assumptions
- New state: 押し出し距離、密着除外、slowと免疫
- Expected boundary: Limited: 距離・slow・coverage・Power域。
- Gate: evidence-required

### Totem of Regeneration

3点の旧表を現行total healingへ対応付け、tick/overlapを確認。

- Reuse: Healing capacity
- New state: zone lifetime、tick、residence、重複配置
- Expected boundary: Limited: residence/party/Power域。
- Gate: evidence-required

## Close gates

1. Preserve the reproducible primary 44 / secondary display 45 / normalized union 45 reconciliation and its non-exhaustive raw-ID caveat.
2. For each batch candidate obtain versioned Power samples/coefficient, units, random-roll semantics and target/stack policy. No curve borrowing or extrapolation.
3. Release only evidence-supported additions; report the candidates that remain Research-only.
4. Implement effect-specific validators, rejection reasons and real state/effect channels before catalog/ArtifactId additions.
5. Keep all historical melee partials and runtime support unchanged.
